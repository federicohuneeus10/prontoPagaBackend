# AI Interactions

Used Claude (claude.ai) as a development assistant throughout the project.

## Prompts used

1. "Set up Node.js + TypeScript with Express and tsx. What's the cleanest way to structure routes, controllers and services for a small REST API?"

2. "What's the right way to extend the Express Request type in TypeScript to attach a decoded JWT payload without using any hacks?"

3. "I want to sign a JWT with a conditional payload in TypeScript — role and sub always, rut only if role is user. Best practice for typing the payload object?"

4. "Write me an auth middleware that validates Bearer tokens and a separate authorization middleware that enforces role-based access on a route param. How do I chain them cleanly in Express?"

5. "What's a simple deterministic hash I can use to map a string to a number in range 0-100? No external libraries."

6. "Express isn't registering my route — getting 404 but the file exists and is imported. What are the common causes?"
